# Wedding Invitation Showcase

GitHub Pages向けの静的ショーケースです。トップのカードから、各イベントパターンの個別ページへ遷移できます。

- `/washiki/` 結婚式・和風
- `/wedding-western/` 洋風ウェディング
- `/after-party/` 二次会
- `/after-party-calm/` 落ち着いた二次会
- `/reunion/` 同窓会
- `/celebration/` 周年・記念イベント

ポートフォリオ公開用の静的サイトです。RSVP、Firebase、管理画面などの本番機能は含めず、デザインとサービス概要のみを掲載します。

GitHub Pagesで公開できます。
